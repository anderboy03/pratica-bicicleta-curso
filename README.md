
# 🚴 Bikcraft - Bicicletas Elétricas

Projeto de site fictício para a marca **Bikcraft**, desenvolvido em HTML e CSS.  
O objetivo é praticar estruturação de páginas, semântica e estilização.

## 📂 Páginas do Projeto
- `index.html` → Página inicial com introdução, lista de bicicletas, parceiros e depoimento.
- `bicicletas.html` → Catálogo de modelos (Nimbus Stark, Magic Might, Nebula Cosmic).
- `seguros.html` → Planos de seguro (Prata e Ouro) e vantagens.
- `termos.html` → Termos e condições de uso.
- `contato.html` → Página de contato (telefone, email, endereço).

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- Git & GitHub
